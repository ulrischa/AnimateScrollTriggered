Animate Scroll Triggered

A tiny CSS-only scroll-trigger adapter for Animate.css.

Animate.css remains unchanged. The extra class only controls when the existing time-based animation is played.

1. Default reveal

The default trigger waits until the element has entered the viewport. The animation stays active until the element leaves the viewport.

class="card animate__animated animate__fadeInUp animate-triggered"

2. Early trigger

This element starts earlier. Use this when the animation should begin while the element is still entering the viewport.

class="card animate__animated animate__fadeInLeft animate-triggered animate-triggered--early"

3. Late trigger

This element starts later. Use this when the element should be clearly inside the viewport before the animation begins.

class="card animate__animated animate__fadeInDown animate-triggered animate-triggered--late"

4. Per-element control

Custom properties can adjust the trigger range on a single element. Animate.css properties such as duration still work normally.

style="--animate-trigger-activation: entry 80% exit 0%; --animate-duration: 1.8s;"

5. Play forward only

This animation plays when entering the trigger range, but it does not reverse when leaving it.

class="card animate__animated animate__fadeInUp animate-triggered animate-triggered--once"

7a. Side by side

This element uses the same internal trigger name as the next one.

7b. Scoped trigger

trigger-scope prevents one element from stealing another element's trigger.

8. Tall element edge case

This element is taller than the viewport. It uses an entry/exit range because a contain range would not be a good fit for an oversized element.

style="--animate-trigger-activation: entry 70% exit 30%;"
